## Findings

### 1. A failed read can rebuild an existing PR

- Category: Reliability; action level: `remediation_recommended`; status: `implemented`
- Raised on: `10fb4c8`; location: `.github/polson/phase.sh` lines 109-109 (right)
- Finding id: `3d950343-f307-4e95-99de-027d397e147f`

Description:

````text
`find_pr` does not check whether `found=$(cat)` succeeds, so a failed read can leave `found` empty while `count` remains valid. If `cat` is unavailable or fails after jq counts one matching PR, the `find-pr` command selects `next=build` instead of failing the step.
````

Evidence explanation:

````text
The new command substitution at line 109 has no status check; `find_pr` is called in an `||` context, so `set -e` does not stop it there. The subsequent check validates only `count`, and the caller interprets an empty `found` as no open PR.
````
